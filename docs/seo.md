# Ree SEO configuration

Primary origin: **https://ree.bd**. The app redirects `www.ree.bd` to the primary origin with a permanent 308 redirect while preserving the path and query string. Both hostnames must be connected to the deployment for that redirect to receive traffic.

## Brand and content

Ree's search positioning is luxury fashion in Bangladesh, with Bengali heritage, rural craft, tradition and living history as its creative foundations. “Not everything old belongs in the past” and “Old is gold” connect that positioning to the brand story. These themes appear in visible homepage/About copy as well as page metadata.

Shared identity, official social profiles and the indexing allowlist live in `src/data/site.ts`. Metadata, canonical URLs and structured data are generated by `src/lib/seo.ts`.

## Prelaunch indexing

Only these finished brand pages are currently indexable and included in `/sitemap.xml`:

- `/` — coming-soon homepage and brand introduction.
- `/about` — Bengali heritage, rural craft and Ree's creative direction.
- `/contact` — Dhaka contact information and official social profiles.

`/landing`, `/shop`, department pages, collections, products, journal previews, legal drafts, cart and checkout use `noindex, follow`. Their canonical URLs and sharing metadata are still configured. New routes inherit `noindex` until they explicitly use the metadata helper and join the indexing allowlist.

`/robots.txt` allows crawling so search engines can read those `noindex` instructions. Do not block these pages in robots.txt: [Google needs to crawl a page to see its noindex directive](https://developers.google.com/search/docs/crawling-indexing/block-indexing).

## Structured data and social cards

- The homepage includes `Organization` and `WebSite` JSON-LD with the real brand, logo, Dhaka location, contact information and the three supplied social profiles.
- About and Contact include page types and breadcrumbs. JSON-LD is serialized with `<` escaped.
- No invented reviews, ratings, product availability, prices, shipping promises or return policies are emitted as structured data. The catalog is currently a preview.
- Each page has a distinct title, description, canonical URL, Open Graph metadata and a Twitter/X sharing card. The content is English, using the `en_BD` Open Graph locale. No untranslated alternate-language pages are advertised.
- Brand sharing assets are `public/seo/ree-social.png` (1200 × 630) and `public/seo/ree-logo.png` (512 × 512). Rebuild from the existing vector identity with `npm run build:seo-assets`.

## Validation

```sh
npm run build
node scripts/check-seo.mjs http://localhost:3001
```

The checks inspect rendered HTML on 18 representative routes, index/noindex rules, unique titles, canonical URLs, Open Graph/Twitter metadata, JSON-LD, the sitemap, robots.txt, image dimensions, the www redirect and real 404 handling. The second command requires a running local server; pass another origin to check a different deployment.

## After deployment

1. Verify the `ree.bd` domain property in Google Search Console using the DNS record supplied by Google. No verification token or Search Console access was supplied in this task.
2. Submit `https://ree.bd/sitemap.xml` and inspect `/`, `/about` and `/contact` with URL Inspection.
3. Validate deployed structured data with Google's Rich Results Test and the Schema.org validator. Monitor indexing and search queries in Search Console.
4. Before the shop launches, replace sample catalog content and policies with approved details. Add finished routes to `indexablePaths`, including individual product and collection URLs, then rerun the SEO checks with the new expected indexing policy. Add factual Product/Offer data only once prices, availability and ordering are real.
5. Publish original craft and maker stories when ready. Give real articles their own URLs and editorial dates before enabling journal indexing.

Search visibility depends on crawling, relevant content and other signals; metadata does not guarantee rankings. Reference: [Google's SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [Organization structured data](https://developers.google.com/search/docs/appearance/structured-data/organization), and [structured data content guidelines](https://developers.google.com/search/docs/appearance/structured-data/sd-policies).
